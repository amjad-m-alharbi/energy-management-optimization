# Energy Management Optimization for a Solar-Battery System

This project presents an optimization model for managing energy flow between solar power, battery storage, and the electrical grid using Python and Google Colab.

## Project Features
- Battery charging/discharging optimization
- Grid power management
- Load demand analysis
- Multiple case studies
- Energy cost minimization

## Case Studies
- Reducing battery capacity
- Increasing battery capacity
- Changing initial battery state of charge
- Increasing peak load demand

## Tools Used
- Python
- Google Colab
- CVXPY
- Pandas
- Matplotlib
